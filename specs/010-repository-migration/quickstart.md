# Quickstart: Repository Migration

## Source topology and identity

```bash
pixi run pytest tests/production_boundary -q
pixi run --environment default production-boundary
pixi run --environment default production-import-check
```

Expected: derived package identity tests pass; boundary and editable import checks report
valid with zero workbench leakage. The import check is not wheel certification.

## RST preservation evidence and comparator

```bash
pixi run pytest tests/production_boundary/test_rst_baseline.py -q
```

Expected: the immutable historical comparison covers all nine records, has no analytical
differences, and the comparator rejects causal analytical mutations. Do not recapture the
pre-migration snapshot with today’s changed formats or substitute current DMRST/UniRST
models for its historical ModernBERT records.

## Repository gates

```bash
pixi run lint
pixi run typecheck
pixi run mdlint
pixi run test
```

Historical 6.0.0 release records are not regenerated by this quickstart. A new clean
artifact build belongs to an explicitly requested, versioned release operation.
